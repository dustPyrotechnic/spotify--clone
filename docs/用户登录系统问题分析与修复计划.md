## 🔍 详细问题分析

### 1. 🔴 严重：App 启动时没有恢复登录会话

**问题描述**
- App 启动时从未调用 `[[XCAuthService sharedInstance] restoreSessionWithCompletion:]`
- 即使之前已登录，每次启动应用用户都需要重新登录

**涉及文件**
- `Spotify - clone/AppDelegate.m`
- `Spotify - clone/SceneDelegate.mm`

**当前代码 (SceneDelegate.mm)**
```objc
- (void)scene:(UIScene *)scene willConnectToSession:(UISceneSession *)session options:(UISceneConnectionOptions *)connectionOptions {
    self.window.frame = ((UIWindowScene *)scene).screen.bounds;
    
    // ❌ 缺少会话恢复
    MainTabBarController* mainTabBarController = [[MainTabBarController alloc] init];
    self.window.rootViewController = mainTabBarController;
    [self.window makeKeyAndVisible];
}
```

**影响**
- 用户体验极差，登录状态无法持久化
- 每次启动都需要重新输入账号密码

---

### 2. 🔴 严重：Token 存储不安全

**问题描述**
- `refreshToken`、`username`、`userId` 都存储在 `NSUserDefaults` 中
- NSUserDefaults 数据可以被轻易读取（越狱设备或备份文件）

**涉及文件**
- `Spotify - clone/6. 网络请求部分/XCAuthService.m` (第 70-86 行)

**当前代码**
```objc
- (void)saveRefreshToken:(NSString *)refreshToken username:(NSString *)username userId:(NSString *)userId {
  NSUserDefaults *ud = [NSUserDefaults standardUserDefaults];
  if (refreshToken) [ud setObject:refreshToken forKey:kRefreshTokenKey];
  if (username)     [ud setObject:username     forKey:kUsernameKey];
  if (userId)       [ud setObject:userId       forKey:kUserIdKey];
  [ud synchronize];
}
```

**风险分析**
| 存储方式 | 安全性 | 越狱设备可读 | 备份加密 |
|---------|-------|-------------|---------|
| NSUserDefaults | ⚠️ 低 | ✅ 是 | ❌ 否 |
| Keychain | ✅ 高 | ⚠️ 困难 | ✅ 是 |

**项目已有资源**
- Podfile 中已包含 `UICKeyChainStore` (v2.2.1)
- 未在登录模块中使用

---

### 3. 🟡 中等：`isLoggedIn` 判断逻辑有缺陷

**问题描述**
- 只检查 `accessToken` 是否存在，没有验证是否过期

**涉及文件**
- `Spotify - clone/6. 网络请求部分/XCAuthService.m` (第 52-54 行)

**当前代码**
```objc
- (BOOL)isLoggedIn {
    return (self.accessToken.length > 0);  // ❌ 不检查过期时间！
}
```

**影响**
- 过期的 accessToken 仍然返回 `isLoggedIn = YES`
- 导致后续 API 调用失败，用户体验差

---

### 4. 🟡 中等：域名配置缺失

**问题描述**
- 登录 API 使用 `http://xiaochenstudio.com/api`
- Info.plist 中没有为此域名配置 `NSExceptionAllowsInsecureHTTPLoads`

**涉及文件**
- `Spotify - clone/Info.plist` (第 11-43 行)

**当前配置**
```xml
<key>NSExceptionDomains</key>
<dict>
    <key>126.net</key>
    ...
    <key>music.126.net</key>
    ...
    <!-- ❌ 缺少 xiaochenstudio.com -->
</dict>
```

**注意**
- 虽然有 `NSAllowsArbitraryLoads: true`，但这不符合最佳实践
- 建议显式配置安全域

---

### 5. 🟡 中等：无密码安全策略

**问题描述**
- 密码输入框没有最小长度限制
- 没有密码强度检查
- 明文传输密码（HTTP 而非 HTTPS）

**涉及文件**
- `Spotify - clone/9. 登录注册界面/XCAuthView.m`
- `Spotify - clone/6. 网络请求部分/XCAuthService.m`

### 6. 🟡 中等：缺少登录状态全局监听

**涉及文件**

**影响**

- 登出后无法自动清理用户相关数据

#### 1.2 Token 安全存储（使用 Keychain）

**文件**: `XCAuthService.m`

**步骤 1**: 导入头文件


**步骤 2**: 定义 Keychain 服务名

**步骤 3**: 替换存储方法
```objc
// 替换 saveRefreshToken 方法
- (void)saveRefreshToken:(NSString *)refreshToken username:(NSString *)username userId:(NSString *)userId {
    UICKeyChainStore *keychain = [UICKeyChainStore keyChainStoreWithService:kKeychainService];
    if (refreshToken) [keychain setString:refreshToken forKey:kRefreshTokenKey];
    if (username)     [keychain setString:username     forKey:kUsernameKey];
    if (userId)       [keychain setString:userId       forKey:kUserIdKey];
}

// 替换 clearAllTokens 方法
- (void)clearAllTokens {
    self.accessToken = nil;
    self.accessTokenExpiresAt = nil;
    UICKeyChainStore *keychain = [UICKeyChainStore keyChainStoreWithService:kKeychainService];
    [keychain removeItemForKey:kRefreshTokenKey];
    [keychain removeItemForKey:kUsernameKey];
    [keychain removeItemForKey:kUserIdKey];
}

// 替换 refreshToken getter
- (NSString *)refreshToken {
    UICKeyChainStore *keychain = [UICKeyChainStore keyChainStoreWithService:kKeychainService];
    return keychain[kRefreshTokenKey];
}

// 替换 username getter
- (NSString *)username {
    UICKeyChainStore *keychain = [UICKeyChainStore keyChainStoreWithService:kKeychainService];
    return keychain[kUsernameKey];
}

// 替换 userId getter
- (NSString *)userId {
    UICKeyChainStore *keychain = [UICKeyChainStore keyChainStoreWithService:kKeychainService];
    return keychain[kUserIdKey];
}
```

**预计工作量**: 1 小时

### 阶段 2: 安全加固（P1 - 应该修复）

#### 2.1 修复 `isLoggedIn` 逻辑

**文件**: `XCAuthService.m`

```objc
- (BOOL)isLoggedIn {
    // 1. 检查 accessToken 是否存在
    if (self.accessToken.length == 0) return NO;
    
    // 2. 检查是否过期（预留 60 秒缓冲时间）
    if (self.accessTokenExpiresAt) {
        NSDate *threshold = [NSDate dateWithTimeIntervalSinceNow:60];
        if ([self.accessTokenExpiresAt compare:threshold] == NSOrderedAscending) {
            return NO; // 已过期或即将过期
        }
    }
    
    // 3. 检查 refreshToken 是否存在（用于后续刷新）
    return (self.refreshToken.length > 0);
}
```

**预计工作量**: 30 分钟

```objc
}
```
