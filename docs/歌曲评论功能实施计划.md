# 歌曲评论功能实施计划

> 文档版本: 1.0  
> 创建日期: 2026-03-03  
> 预计工期: 5-6 天

---

## 1. 项目概述

### 1.1 目标
在播放详情页（XCMusicPlayerViewController）中集成歌曲评论展示功能，支持主评论列表、长评论折叠展开、楼层评论展示。

### 1.2 核心特性
- 评论面板与播放控制区协同动画
- 长评论折叠/展开（120字阈值）
- 楼层评论页面（独立导航页）
- 延迟预加载机制（无缓存，仅当前歌曲）

## 2. 实施阶段

### Phase 1: 网络层与数据模型（Day 1）✅ 已完成

**目标**: 建立数据基础和网络通信能力

**任务清单**:
1. 创建 `XCSongCommentService` 网络服务类
   - 封装 `/comment/music` 接口（主评论列表）
   - 封装 `/comment/floor` 接口（楼层评论）
   - 实现请求取消机制

2. 创建数据模型
   - `XCSongComment`: 单条评论数据（含 replyToComment, replyCount, parentCommentId）
   - `XCSongCommentList`: 主评论列表管理（含高度缓存）
   - `XCSongCommentFloorList`: 楼层评论列表管理

3. 集成预加载到 `XCMusicPlayerModel`
   - 添加 `preloadedCommentList` 属性
   - 切歌后延迟 2 秒预加载评论
   - 切歌时取消旧请求并释放内存

**验收标准**:
- 网络请求正常返回数据
- 数据模型能正确解析 JSON
- 预加载机制在切歌时正常工作

**完成摘要**:

- ✅ 创建 `XCSongComment` - 数据模型，含回复关系、长评论标记（>120字）
- ✅ 创建 `XCSongCommentList` - 主评论列表管理，含高度预计算和缓存

### Phase 4: 长评论折叠展开（Day 4 上午）

**目标**: 实现长评论的折叠/展开功能

**任务清单**:
1. 高度预计算

2. 展开/收起逻辑
   - 点击"展开"：更新 `isExpanded` 状态，重新计算高度
   - 使用 `beginUpdates/endUpdates` 动画刷新行高
   - 按钮文字切换（展开→收起），箭头旋转

3. 边界处理
   - 展开后内容超出屏幕时支持滚动查看
   - 收起时恢复到折叠高度

**验收标准**:
- 长评论默认折叠显示
- 点击展开动画平滑
- 列表滑动不卡顿（高度已预计算）

## 4. 风险与应对

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| 网易云 API 不稳定 | 中 | 高 | 添加重试机制，失败时友好提示 |
| 评论数据量过大导致内存压力 | 低 | 中 | 限制单次加载数量（20条），分页加载 |
| 动画与音频播放冲突 | 低 | 中 | 动画使用 transform，不阻塞主线程 |
| 快速切歌时请求管理混乱 | 中 | 中 | 确保 cancel 机制正确，避免回调崩溃 |
| 长评论展开后表格跳动 | 低 | 低 | 使用预计算高度，不用自动计算 |
