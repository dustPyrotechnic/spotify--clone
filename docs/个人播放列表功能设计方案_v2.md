## 三、WCDB 数据模型设计

### 3.1 播放列表实体：扩展 `XC_YYAlbumData`

**原则**：`XC_YYAlbumData` 的现有字段天然对应播放列表概念，只需新增 5 个本地字段并实现 `WCTTableCoding`。

**字段映射：**

| 现有字段 | 播放列表语义 | WCDB 列名 |
|---------|------------|----------|
| `albumId` | 播放列表 ID（主键） | `albumId` (PRIMARY KEY) |
| `name` | 播放列表名称 | `name` |
| `coverImgUrl` | 封面 URL | `coverImgUrl` |
| `artistName` | 创建者（本地创建时为空） | `artistName` |

**新增字段（纯本地，不参与 YYModel 网络映射）：**

```objc
// 新增到 XC-YYAlbumData.h
@property (nonatomic, assign) NSInteger createTime;   // 创建时间戳（Unix ms）
@property (nonatomic, assign) NSInteger updateTime;   // 最近更新时间（用于排序）
@property (nonatomic, assign) NSInteger songCount;    // 歌曲数量（冗余，避免 join）
@property (nonatomic, assign) BOOL isFavorites;       // 是否为内置「喜爱的歌曲」
@property (nonatomic, assign) NSInteger sortIndex;    // 手动排序序号（预留）
```

**WCDB 实现（`.m` 改为 `.mm`）：**

```objc
// XC-YYAlbumData.mm 中添加
#import <WCDBObjc/WCDBObjc.h>

@implementation XC_YYAlbumData

WCDB_IMPLEMENTATION(XC_YYAlbumData)
WCDB_SYNTHESIZE(albumId)       // PRIMARY KEY
WCDB_SYNTHESIZE(name)
WCDB_SYNTHESIZE(coverImgUrl)
WCDB_SYNTHESIZE(artistName)
WCDB_SYNTHESIZE(createTime)
WCDB_SYNTHESIZE(updateTime)
WCDB_SYNTHESIZE(songCount)
WCDB_SYNTHESIZE(isFavorites)
WCDB_SYNTHESIZE(sortIndex)
WCDB_PRIMARY(albumId)

// YYModel 现有代码保持不变...
@end
```

> **重要**：YYModel 和 WCTTableCoding 协议完全独立。API 返回的 JSON 不含 `createTime` 等字段，YYModel 解析时这些字段保持默认值 0/NO，不影响现有网络请求功能。

### 3.2 播放列表-歌曲关联：扩展 `XC_YYSongData`

**v2 调整说明**：v1 方案中同一首歌加入多个播放列表会产生多条 `XC_YYSongData` 记录（`playlistId` 不同）。这是标准关联表行为，可行，但存储了歌曲的重复信息。v2 **保持 v1 方案**（简单且够用），但明确说明：

- `playlistId` 作为逻辑外键（WCDB 中不设物理外键约束）
- `(playlistId, songId)` 通过查询条件保证唯一性（每首歌在每个列表只出现一次）

**新增字段（纯本地）：**

```objc
// 新增到 XC-YYSongData.h
@property (nonatomic, copy, nullable) NSString *playlistId; // 所属播放列表 ID
@property (nonatomic, assign) NSInteger sortOrder;          // 在列表内的排序
@property (nonatomic, assign) NSInteger addedTime;          // 加入时间戳（Unix ms）
```

**数据表结构（WCDB 自动建表）：**

```
表名：XC_YYSongData（由 WCDB_IMPLEMENTATION 宏指定）

| 列名        | 类型    | 约束              |
|-------------|---------|-------------------|
| songId      | TEXT    | NOT NULL          |
| playlistId  | TEXT    | NOT NULL          |
| name        | TEXT    |                   |
| artist      | TEXT    |                   |
| mainIma     | TEXT    |                   |
| duration    | INTEGER |                   |
| albumName   | TEXT    |                   |
| addedTime   | INTEGER |                   |
| sortOrder   | INTEGER | DEFAULT 0         |
| ...其他字段 |         |                   |

查询时以 WHERE playlistId = ? 过滤，等效于联合主键
```

### 3.3 数据库管理器：`XCPlaylistDatabaseManager`

**文件路径**：`Spotify - clone/数据库/XCPlaylistDatabaseManager.h/.mm`

**单例模式**（与项目其他单例一致，使用饿汉式）：

```objc
+ (void)load {
    instance = [[super allocWithZone:NULL] init];
    [instance initializeDatabaseIfNeeded];
}
```

**完整接口：**

```objc
@interface XCPlaylistDatabaseManager : NSObject

+ (instancetype)sharedInstance;

#pragma mark - 数据库初始化
/// App 首次运行时建表 + 创建内置「喜爱的歌曲」播放列表
- (void)initializeDatabaseIfNeeded;

#pragma mark - 播放列表 CRUD
/// 获取所有播放列表（喜爱的歌曲固定排首位，其余按 sortType 排序）
- (NSArray<XC_YYAlbumData *> *)getAllPlaylistsSortedBy:(XCPlaylistSortType)sortType;

/// 新建播放列表（自动生成 UUID 作为 albumId，设置 createTime/updateTime）
- (nullable XC_YYAlbumData *)createPlaylistWithName:(NSString *)name;

/// 删除播放列表及其所有歌曲记录（isFavorites=YES 时返回 NO，不允许删除）
- (BOOL)deletePlaylistWithId:(NSString *)playlistId;

/// 修改播放列表名称
- (BOOL)renamePlaylist:(NSString *)playlistId newName:(NSString *)name;

/// 更新封面 URL（添加第一首歌时自动调用）
- (void)updateCoverUrl:(NSString *)coverUrl forPlaylistId:(NSString *)playlistId;

#pragma mark - 歌曲 CRUD
/// 获取播放列表内所有歌曲（按 addedTime 升序），直接返回 XC_YYSongData 数组
/// @note 返回值可直接赋给 XCALbumDetailModel.playerList，零转换
- (NSMutableArray<XC_YYSongData *> *)getSongsOfPlaylist:(NSString *)playlistId;

/// 添加歌曲到播放列表
/// @return YES：添加成功；NO：歌曲已存在于该播放列表中
- (BOOL)addSong:(XC_YYSongData *)song toPlaylist:(NSString *)playlistId;

/// 从播放列表移除歌曲
- (BOOL)removeSong:(NSString *)songId fromPlaylist:(NSString *)playlistId;

/// 检查歌曲是否已在播放列表中（用于 menuButton 状态显示）
- (BOOL)isSong:(NSString *)songId inPlaylist:(NSString *)playlistId;

/// 获取「喜爱的歌曲」列表（albumId 固定为 @"favorites"）
- (XC_YYAlbumData *)getFavoritesPlaylist;

@end
```

**排序类型：**

```objc
typedef NS_ENUM(NSInteger, XCPlaylistSortType) {
    XCPlaylistSortByUpdateTime = 0,   // 最近更新（默认）
    XCPlaylistSortByCreateTime = 1,   // 最近创建
    XCPlaylistSortByName       = 2,   // 名称 A-Z
};
```

**数据库文件路径**：`Library/Application Support/XCPlaylist.db`

- (void)tableView:(UITableView *)tableView didSelectRowAtIndexPath:(NSIndexPath *)indexPath {
    XC_YYAlbumData *playlist = self.model.playlists[indexPath.row];

    XCALbumDetailViewController *detailVC = [[XCALbumDetailViewController alloc] init];

### 5.2 XCALbumDetailViewController 改动

**修改文件**：`详细页面/XCALbumDetailViewController.m`

在 `giveData:ToCell:` 方法中，为每个 cell 设置 block：

```objc
- (void)giveData:(XC_YYSongData *)song ToCell:(XCAlbumDetailCell *)cell {
    // 现有赋值代码...

    // 新增：设置 menuButton 回调
    __weak typeof(self) weakSelf = self;
    cell.menuButtonBlock = ^(NSString *songId) {
        [weakSelf showMenuForSong:song];
    };
}

- (void)showMenuForSong:(XC_YYSongData *)song {
    UIAlertController *sheet = [UIAlertController
        alertControllerWithTitle:song.name
                         message:nil
                  preferredStyle:UIAlertControllerStyleActionSheet];

    // 是否已收藏，动态显示文案
    BOOL isLiked = [[XCPlaylistDatabaseManager sharedInstance]
                    isSong:song.songId inPlaylist:@"favorites"];
    NSString *likeTitle = isLiked ? @"从喜爱的歌曲移除" : @"加入喜爱的歌曲";

    [sheet addAction:[UIAlertAction actionWithTitle:likeTitle
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *_) {
        if (isLiked) {
            [[XCPlaylistDatabaseManager sharedInstance]
                removeSong:song.songId fromPlaylist:@"favorites"];
        } else {
            [[XCPlaylistDatabaseManager sharedInstance]
                addSong:song toPlaylist:@"favorites"];
        }
    }]];

    [sheet addAction:[UIAlertAction actionWithTitle:@"加入播放列表…"
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *_) {
        [weakSelf showPlaylistPickerForSong:song];
    }]];

    [sheet addAction:[UIAlertAction actionWithTitle:@"取消"
                                             style:UIAlertActionStyleCancel
                                           handler:nil]];

    [self presentViewController:sheet animated:YES completion:nil];
}

- (void)showPlaylistPickerForSong:(XC_YYSongData *)song {
    // 获取所有非内置播放列表
    NSArray<XC_YYAlbumData *> *playlists =
        [[XCPlaylistDatabaseManager sharedInstance] getAllPlaylistsSortedBy:XCPlaylistSortByUpdateTime];

    UIAlertController *picker = [UIAlertController
        alertControllerWithTitle:@"选择播放列表"
                         message:nil
                  preferredStyle:UIAlertControllerStyleActionSheet];

    for (XC_YYAlbumData *playlist in playlists) {
        [picker addAction:[UIAlertAction actionWithTitle:playlist.name
                                                  style:UIAlertActionStyleDefault
                                                handler:^(UIAlertAction *_) {
            BOOL added = [[XCPlaylistDatabaseManager sharedInstance]
                          addSong:song toPlaylist:playlist.albumId];
            if (!added) {
                // 已存在，可以 Toast 提示
                NSLog(@"[Playlist] 歌曲已在播放列表中");
            }
        }]];
    }

    [picker addAction:[UIAlertAction actionWithTitle:@"取消"
                                              style:UIAlertActionStyleCancel
                                            handler:nil]];

    [self presentViewController:picker animated:YES completion:nil];
}
```

## 六、数据流程

### 启动初始化

```
AppDelegate.didFinishLaunchingWithOptions
    └── [XCPlaylistDatabaseManager sharedInstance]（+load 时自动调用 initializeDatabaseIfNeeded）
        └── [_database createTable:@"XC_YYAlbumData" withClass:XC_YYAlbumData.class]
        └── [_database createTable:@"XC_YYSongData" withClass:XC_YYSongData.class]
        └── 检查是否存在 isFavorites=1 的记录
            └── 不存在 → INSERT XC_YYAlbumData(albumId=@"favorites", isFavorites=YES, name=@"喜爱的歌曲")
```

### 加载播放列表主页

```
XCPersonalViewController.viewWillAppear
    └── [self.model loadPlaylists]
        └── [XCPlaylistDatabaseManager getAllPlaylistsSortedBy:XCPlaylistSortByUpdateTime]
            ├── SELECT * FROM XC_YYAlbumData WHERE isFavorites=1（置顶）
            └── SELECT * FROM XC_YYAlbumData WHERE isFavorites=0 ORDER BY updateTime DESC
        └── self.model.playlists = result
    └── [tableView/collectionView reloadData]
```

### 新建播放列表

```
点击「+」→ UIAlertController(style: .alert, TextField)
    └── 用户输入名称，确认
        └── [XCPlaylistDatabaseManager createPlaylistWithName:]
            ├── 生成 UUID 作为 albumId
            ├── 设置 createTime = updateTime = 当前时间戳
            └── INSERT INTO XC_YYAlbumData ...
        └── [model loadPlaylists] → reloadData
```

### 添加歌曲到播放列表

```
XCAlbumDetailCell.menuButton → menuButtonBlock → showMenuForSong:
    └── UIAlertController ActionSheet
        ├── 「加入喜爱的歌曲」
        │   └── [DB addSong:song toPlaylist:@"favorites"]
        │       ├── SELECT 检查是否已存在
        │       ├── 存在 → 返回 NO
        │       └── 不存在 → INSERT INTO XC_YYSongData（含 playlistId=@"favorites"）
        │                   → UPDATE XC_YYAlbumData SET songCount=N+1, coverUrl=... WHERE albumId=@"favorites"
        └── 「加入播放列表…」
            └── 二级 ActionSheet（列出所有播放列表）
                └── 选择目标 → [DB addSong:song toPlaylist:selectedId]
```

### 进入播放列表并播放歌曲

```
XCPersonalViewController.didSelectRow
    └── 填充 XCALbumDetailModel（playerlistName/mainImaUrl/playerList）
    └── push XCALbumDetailViewController

XCALbumDetailViewController.didSelectRow（现有代码，零改动）
    └── [XCMusicPlayerModel.sharedInstance playMusicWithId:song.songId]
    └── XCMusicPlayerModel.playerlist = self.model.playerList
```

## 九、WCDB 数据库关键实现参考

### 建表（XCPlaylistDatabaseManager.mm）

```objc
- (instancetype)init {
    self = [super init];
    if (self) {
        NSString *appSupportDir = [NSSearchPathForDirectoriesInDomains(
            NSApplicationSupportDirectory, NSUserDomainMask, YES) firstObject];
        NSString *dbPath = [appSupportDir stringByAppendingPathComponent:@"XCPlaylist.db"];
        _database = [[WCTDatabase alloc] initWithPath:dbPath];

        // 建表（字段新增时 WCDB 会自动 ALTER TABLE）
        [_database createTable:@"playlists" withClass:XC_YYAlbumData.class];
        [_database createTable:@"playlist_songs" withClass:XC_YYSongData.class];
    }
    return self;
}
```

> **建议**：使用自定义表名（`"playlists"` 和 `"playlist_songs"`），而非默认的类名，以避免与其他地方使用这些模型冲突。
> WCDB 支持同一个类映射到多张表，调用时指定表名即可。

### 查询（以获取播放列表歌曲为例）

```objc
- (NSMutableArray<XC_YYSongData *> *)getSongsOfPlaylist:(NSString *)playlistId {
    NSArray *results = [_database getObjectsOfClass:XC_YYSongData.class
                                          fromTable:@"playlist_songs"
                                              where:XC_YYSongData.playlistId == playlistId
                                            orderBy:XC_YYSongData.addedTime.asOrder()];
    return results ? [results mutableCopy] : [NSMutableArray array];
}
```

### 插入歌曲

```objc
- (BOOL)addSong:(XC_YYSongData *)song toPlaylist:(NSString *)playlistId {
    // 检查重复
    NSInteger count = [_database getOneValueOnResult:XC_YYSongData.songId.count()
                                           fromTable:@"playlist_songs"
                                               where:XC_YYSongData.playlistId == playlistId
                                                     && XC_YYSongData.songId == song.songId].numberValue.integerValue;
    if (count > 0) return NO;

    // 克隆对象并设置关联字段
    XC_YYSongData *record = [song copy]; // 需要 XC_YYSongData 实现 NSCopying
    record.playlistId = playlistId;
    record.addedTime = (NSInteger)([[NSDate date] timeIntervalSince1970] * 1000);

    BOOL success = [_database insertObject:record intoTable:@"playlist_songs"];
    if (success) {
        // 更新 songCount 和 coverUrl（若首次添加）
        [self updateSongCountForPlaylistId:playlistId];
        // ...
    }
    return success;
}
```
