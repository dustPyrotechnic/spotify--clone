## 三表规范化设计

> 创建日期：2026-02-22
> 基于 v2 升级，切换为三表规范化数据库设计，消除歌曲数据冗余
> 分支：自己写个人播放列表

## 三、WCDB 数据模型设计

### 3.1 播放列表实体：扩展 `XC_YYAlbumData`

**原则**：`XC_YYAlbumData` 的现有字段天然对应播放列表概念，只需新增 5 个本地字段并实现 `WCTTableCoding`。

**字段映射：**

| 现有字段 | 播放列表语义 | WCDB 列名 |
|---------|------------|----------|
| `albumId` | 播放列表 ID（主键） | `albumId` (PRIMARY KEY) |
| `name` | 播放列表名称 | `name` |
| `coverImgUrl` | 封面 URL | `coverImgUrl` |
| `artistName` | 创建者（本地创建时为空） | `artistName` |

**新增字段（纯本地，不参与 YYModel 网络映射）：**

```objc
// 新增到 XC-YYAlbumData.h
@property (nonatomic, assign) NSInteger createTime;   // 创建时间戳（Unix ms）
@property (nonatomic, assign) NSInteger updateTime;   // 最近更新时间（用于排序）
@property (nonatomic, assign) NSInteger songCount;    // 歌曲数量（冗余，避免 join）
@property (nonatomic, assign) BOOL isFavorites;       // 是否为内置「喜爱的歌曲」
@property (nonatomic, assign) NSInteger sortIndex;    // 手动排序序号（预留）
```

**WCDB 实现（`.m` 改为 `.mm`）：**

```objc
// XC-YYAlbumData.mm 中添加
#import <WCDBObjc/WCDBObjc.h>

@implementation XC_YYAlbumData

WCDB_IMPLEMENTATION(XC_YYAlbumData)
WCDB_SYNTHESIZE(albumId)
WCDB_SYNTHESIZE(name)
WCDB_SYNTHESIZE(coverImgUrl)
WCDB_SYNTHESIZE(artistName)
WCDB_SYNTHESIZE(authorId)
WCDB_SYNTHESIZE(createTime)
WCDB_SYNTHESIZE(updateTime)
WCDB_SYNTHESIZE(songCount)
WCDB_SYNTHESIZE(isFavorites)
WCDB_SYNTHESIZE(sortIndex)
WCDB_PRIMARY(albumId)

// YYModel 现有代码保持不变...
@end
```

### 3.2 关联表：新建 `XCPlaylistSongRelation`

**v3 核心变化**：不再向 `XC_YYSongData` 添加 `playlistId`、`sortOrder`、`addedTime` 字段。
同一首歌加入多个播放列表时，`songs` 表只存一条记录，关联关系存在独立的 `playlist_song_relations` 表中。

**文件路径**：`Spotify - clone/数据库/XCPlaylistSongRelation.h/.mm`

**字段定义：**

```objc
@interface XCPlaylistSongRelation : NSObject <WCTTableCoding>

@property (nonatomic, copy) NSString *playlistId;  // 外键→playlists.albumId
@property (nonatomic, copy) NSString *songId;       // 外键→songs.songId
@property (nonatomic, assign) NSInteger addedTime;  // Unix 毫秒，用于排序
@property (nonatomic, assign) NSInteger sortOrder;  // 手动排序，预留

WCDB_PROPERTY(playlistId)
WCDB_PROPERTY(songId)
WCDB_PROPERTY(addedTime)
WCDB_PROPERTY(sortOrder)

@end
```

**数据表结构：**

```
表名：playlist_song_relations

| 列名        | 类型    | 说明                            |
|-------------|---------|--------------------------------|
| playlistId  | TEXT    | 外键，引用 playlists.albumId    |
| songId      | TEXT    | 外键，引用 songs.songId         |
| addedTime   | INTEGER | Unix ms，用于按加入时间排序     |
| sortOrder   | INTEGER | 手动排序，预留字段              |

唯一性：(playlistId, songId) 通过插入前检查保证不重复
```

### 3.3 数据库管理器：`XCPlaylistDatabaseManager`

**文件路径**：`Spotify - clone/数据库/XCPlaylistDatabaseManager.h/.mm`

**单例模式**（饿汉式，与项目其他单例一致）：

```objc
+ (void)load {
    instance = [[super allocWithZone:NULL] init];
    [instance initializeDatabaseIfNeeded];
}
```

**完整接口：**

```objc
@interface XCPlaylistDatabaseManager : NSObject

+ (instancetype)sharedInstance;

#pragma mark - 数据库初始化
/// App 首次运行时建三张表 + 创建内置「喜爱的歌曲」播放列表
- (void)initializeDatabaseIfNeeded;

#pragma mark - 播放列表 CRUD
/// 获取所有播放列表（喜爱的歌曲固定排首位，其余按 sortType 排序）
- (NSArray<XC_YYAlbumData *> *)getAllPlaylistsSortedBy:(XCPlaylistSortType)sortType;

/// 新建播放列表（自动生成 UUID 作为 albumId，设置 createTime/updateTime）
- (nullable XC_YYAlbumData *)createPlaylistWithName:(NSString *)name;

/// 删除播放列表及其关联关系（isFavorites=YES 时返回 NO，songs 表不受影响）
- (BOOL)deletePlaylistWithId:(NSString *)playlistId;

/// 修改播放列表名称
- (BOOL)renamePlaylist:(NSString *)playlistId newName:(NSString *)name;

/// 更新封面 URL（添加第一首歌时自动调用）
- (void)updateCoverUrl:(NSString *)coverUrl forPlaylistId:(NSString *)playlistId;

#pragma mark - 歌曲 CRUD
/// 获取播放列表内所有歌曲（两步查询：先查 relations，再查 songs）
/// @note 返回值可直接赋给 XCALbumDetailModel.playerList，零转换
- (NSMutableArray<XC_YYSongData *> *)getSongsOfPlaylist:(NSString *)playlistId;

/// 添加歌曲到播放列表（insertOrReplace 到 songs 表 + insert relation）
/// @return YES：添加成功；NO：歌曲已存在于该播放列表中
- (BOOL)addSong:(XC_YYSongData *)song toPlaylist:(NSString *)playlistId;

/// 从播放列表移除歌曲（只删 relation，songs 表保留）
- (BOOL)removeSong:(NSString *)songId fromPlaylist:(NSString *)playlistId;

/// 检查歌曲是否已在播放列表中（用于 menuButton 状态显示）
- (BOOL)isSong:(NSString *)songId inPlaylist:(NSString *)playlistId;

/// 获取「喜爱的歌曲」列表（albumId 固定为 @"favorites"）
- (XC_YYAlbumData *)getFavoritesPlaylist;

/// 清理孤立歌曲（不被任何播放列表引用的 songs 表记录），返回清理数量
- (NSInteger)cleanOrphanSongs;

@end
```

**排序类型：**

```objc
typedef NS_ENUM(NSInteger, XCPlaylistSortType) {
    XCPlaylistSortByUpdateTime = 0,   // 最近更新（默认）
    XCPlaylistSortByCreateTime = 1,   // 最近创建
    XCPlaylistSortByName       = 2,   // 名称 A-Z
};
```

**数据库文件路径**：`Library/Application Support/XCPlaylist.db`

### 5.2 XCALbumDetailViewController 改动

```objc
- (void)giveData:(XC_YYSongData *)song ToCell:(XCAlbumDetailCell *)cell {
    // 现有赋值代码...

    __weak typeof(self) weakSelf = self;
    cell.menuButtonBlock = ^(NSString *songId) {
        [weakSelf showMenuForSong:song];
    };
}

- (void)showMenuForSong:(XC_YYSongData *)song {
    UIAlertController *sheet = [UIAlertController
        alertControllerWithTitle:song.name
                         message:nil
                  preferredStyle:UIAlertControllerStyleActionSheet];

    BOOL isLiked = [[XCPlaylistDatabaseManager sharedInstance]
                    isSong:song.songId inPlaylist:@"favorites"];
    NSString *likeTitle = isLiked ? @"从喜爱的歌曲移除" : @"加入喜爱的歌曲";

    [sheet addAction:[UIAlertAction actionWithTitle:likeTitle
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *_) {
        if (isLiked) {
            [[XCPlaylistDatabaseManager sharedInstance]
                removeSong:song.songId fromPlaylist:@"favorites"];
        } else {
            [[XCPlaylistDatabaseManager sharedInstance]
                addSong:song toPlaylist:@"favorites"];
        }
    }]];

    __weak typeof(self) weakSelf = self;
    [sheet addAction:[UIAlertAction actionWithTitle:@"加入播放列表…"
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *_) {
        [weakSelf showPlaylistPickerForSong:song];
    }]];

    [sheet addAction:[UIAlertAction actionWithTitle:@"取消"
                                             style:UIAlertActionStyleCancel
                                           handler:nil]];

    [self presentViewController:sheet animated:YES completion:nil];
}

- (void)showPlaylistPickerForSong:(XC_YYSongData *)song {
    NSArray<XC_YYAlbumData *> *playlists =
        [[XCPlaylistDatabaseManager sharedInstance]
            getAllPlaylistsSortedBy:XCPlaylistSortByUpdateTime];

    UIAlertController *picker = [UIAlertController
        alertControllerWithTitle:@"选择播放列表"
                         message:nil
                  preferredStyle:UIAlertControllerStyleActionSheet];

    for (XC_YYAlbumData *playlist in playlists) {
        [picker addAction:[UIAlertAction actionWithTitle:playlist.name
                                                  style:UIAlertActionStyleDefault
                                                handler:^(UIAlertAction *_) {
            BOOL added = [[XCPlaylistDatabaseManager sharedInstance]
                          addSong:song toPlaylist:playlist.albumId];
            if (!added) {
                NSLog(@"[Playlist] 歌曲已在播放列表中");
            }
        }]];
    }

    [picker addAction:[UIAlertAction actionWithTitle:@"取消"
                                              style:UIAlertActionStyleCancel
                                            handler:nil]];

    [self presentViewController:picker animated:YES completion:nil];
}
```

## 六、数据流程

### 启动初始化

```
+load（饿汉式）→ XCPlaylistDatabaseManager.init → initializeDatabaseIfNeeded
    └── createTable:@"playlists" withClass:XC_YYAlbumData.class
    └── createTable:@"songs" withClass:XC_YYSongData.class
    └── createTable:@"playlist_song_relations" withClass:XCPlaylistSongRelation.class
    └── 检查 favorites 是否存在
        └── 不存在 → INSERT (albumId=@"favorites", isFavorites=YES, name=@"喜爱的歌曲")
```

### getSongsOfPlaylist:（两步查询，v3 核心）

```
Step 1: SELECT * FROM playlist_song_relations
        WHERE playlistId = ?
        ORDER BY addedTime ASC

Step 2: for each relation:
        SELECT * FROM songs WHERE songId = relation.songId

返回有序 NSMutableArray<XC_YYSongData *>，直接赋给 XCALbumDetailModel.playerList
```

### addSong:toPlaylist:（v3 版本）

```
1. SELECT * FROM playlist_song_relations
   WHERE playlistId = ? AND songId = ?
   → 存在：return NO（已存在）

2. insertOrReplace song → songs 表（dedup，同一首歌只存一次）

3. INSERT relation → playlist_song_relations 表

4. 更新 playlists.songCount 和 playlists.updateTime

5. 若 playlists.coverImgUrl 为空且 song.mainIma 有值 → 自动设置封面
```

### deletePlaylistWithId:（v3：只删 relations，songs 表不动）

```
1. 检查 isFavorites=YES → return NO（保护内置列表）
2. DELETE FROM playlist_song_relations WHERE playlistId = ?
3. DELETE FROM playlists WHERE albumId = ?
   （songs 表不动！其他播放列表仍可引用这些歌曲）
```

## 九、WCDB 关键实现参考（v3 三表版本）

### 建三张表（XCPlaylistDatabaseManager.mm）

```objc
- (instancetype)init {
    self = [super init];
    if (self) {
        NSString *appSupportDir = [NSSearchPathForDirectoriesInDomains(
            NSApplicationSupportDirectory, NSUserDomainMask, YES) firstObject];
        NSString *dbPath = [appSupportDir stringByAppendingPathComponent:@"XCPlaylist.db"];
        _database = [[WCTDatabase alloc] initWithPath:dbPath];

        [_database createTable:@"playlists" withClass:XC_YYAlbumData.class];
        [_database createTable:@"songs" withClass:XC_YYSongData.class];
        [_database createTable:@"playlist_song_relations" withClass:XCPlaylistSongRelation.class];
    }
    return self;
}
```

### getSongsOfPlaylist:（两步查询）

```objc
- (NSMutableArray<XC_YYSongData *> *)getSongsOfPlaylist:(NSString *)playlistId {
    // Step 1: 查 relations，按加入时间排序
    NSArray *relations = [_database getObjectsOfClass:XCPlaylistSongRelation.class
                                            fromTable:@"playlist_song_relations"
                                                where:XCPlaylistSongRelation.playlistId == playlistId
                                             orderBy:XCPlaylistSongRelation.addedTime.asOrder()];

    NSMutableArray<XC_YYSongData *> *songs = [NSMutableArray array];
    // Step 2: 根据 songId 逐条查 songs 表
    for (XCPlaylistSongRelation *rel in relations) {
        XC_YYSongData *song = [_database getOneObjectOfClass:XC_YYSongData.class
                                                  fromTable:@"songs"
                                                      where:XC_YYSongData.songId == rel.songId];
        if (song) {
            [songs addObject:song];
        }
    }
    return songs;
}
```

### addSong:toPlaylist:（insertOrReplace 到 songs 表）

```objc
- (BOOL)addSong:(XC_YYSongData *)song toPlaylist:(NSString *)playlistId {
    // 1. 检查是否已存在关联
    XCPlaylistSongRelation *existing =
        [_database getOneObjectOfClass:XCPlaylistSongRelation.class
                             fromTable:@"playlist_song_relations"
                                 where:XCPlaylistSongRelation.playlistId == playlistId
                                       && XCPlaylistSongRelation.songId == song.songId];
    if (existing) return NO;

    // 2. insertOrReplace 到 songs 表（同一首歌只存一次）
    [_database insertOrReplaceObject:song intoTable:@"songs"];

    // 3. 创建关联记录
    XCPlaylistSongRelation *rel = [[XCPlaylistSongRelation alloc] init];
    rel.playlistId = playlistId;
    rel.songId = song.songId;
    rel.addedTime = (NSInteger)([[NSDate date] timeIntervalSince1970] * 1000);
    rel.sortOrder = 0;

    BOOL success = [_database insertObject:rel intoTable:@"playlist_song_relations"];
    if (success) {
        [self updateSongCountForPlaylistId:playlistId];
        [self updateCoverIfNeededForPlaylistId:playlistId withSongImgUrl:song.mainIma];
    }
    return success;
}
```

### deletePlaylistWithId:（只删 relations，songs 表不动）

```objc
- (BOOL)deletePlaylistWithId:(NSString *)playlistId {
    XC_YYAlbumData *playlist = [_database getOneObjectOfClass:XC_YYAlbumData.class
                                                    fromTable:@"playlists"
                                                        where:XC_YYAlbumData.albumId == playlistId];
    if (!playlist || playlist.isFavorites) return NO;

    // 只删 relations，songs 表保留（其他播放列表可能仍引用）
    [_database deleteObjectsFromTable:@"playlist_song_relations"
                                where:XCPlaylistSongRelation.playlistId == playlistId];

    [_database deleteObjectsFromTable:@"playlists"
                                where:XC_YYAlbumData.albumId == playlistId];
    return YES;
}
```
