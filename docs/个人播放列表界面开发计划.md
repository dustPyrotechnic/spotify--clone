## Phase 4: 搜索与筛选功能

### 目标
实现完整的搜索过滤和排序筛选功能。

### 任务清单

- [ ] **4.1 Model 层实现搜索过滤**
  ```objc
  // XCPersonalModel.m
  - (void)filterPlaylistsWithSearchText:(NSString*)searchText {
      if (searchText.length == 0) {
          self.filteredPlaylists = [self.allPlaylists mutableCopy];
      } else {
          NSPredicate* predicate = [NSPredicate predicateWithFormat:@"name CONTAINS[cd] %@", searchText];
          self.filteredPlaylists = [[self.allPlaylists filteredArrayUsingPredicate:predicate] mutableCopy];
      }
      [self applyCurrentSort];  // 保持当前排序
  }
  ```

- [ ] **4.2 Model 层实现排序功能**
  ```objc
  // XCPersonalModel.m
  - (void)sortPlaylistsByType:(XCPlaylistSortType)sortType {
      self.currentSortType = sortType;
      [self applyCurrentSort];
  }
  
  - (void)applyCurrentSort {
      switch (self.currentSortType) {
          case XCPlaylistSortTypeNameAsc:
              [self.filteredPlaylists sortUsingComparator:^NSComparisonResult(XC_YYAlbumData* obj1, XC_YYAlbumData* obj2) {
                  return [obj1.name compare:obj2.name options:NSCaseInsensitiveSearch];
              }];
              break;
          // 其他排序方式...
      }
  }
  ```

- [ ] **4.3 Controller 层集成搜索**
  ```objc
  #pragma mark - UISearchResultsUpdating
  - (void)updateSearchResultsForSearchController:(UISearchController*)searchController {
      NSString* searchText = searchController.searchBar.text;
      // 调用 Model
      [self.model filterPlaylistsWithSearchText:searchText];
      // 更新 View
      [self.mainView.collectionView reloadData];
      [self.mainView showEmptyView:(self.model.filteredPlaylists.count == 0)];
  }
  ```

- [ ] **4.4 Controller 层集成筛选**
  ```objc
  - (void)showSortMenu:(id)sender {
      UIAlertController* alert = [UIAlertController alertControllerWithTitle:@"排序方式" ...];
      
      __weak typeof(self) weakSelf = self;
      [alert addAction:[UIAlertAction actionWithTitle:@"名称 A-Z" style:... handler:^(UIAlertAction * _Nonnull action) {
          // 调用 Model
          [weakSelf.model sortPlaylistsByType:XCPlaylistSortTypeNameAsc];
          // 更新 View
          [weakSelf.mainView.collectionView reloadData];
      }]];
      
      [self presentViewController:alert animated:YES completion:nil];
  }
  ```

### 验收标准

- [ ] 清除搜索词显示全部列表
- [ ] 选择不同排序方式列表重新排序

## Phase 5: 数据交互与跳转

### 目标
实现播放列表的创建、删除，以及点击进入详细页面。

### 任务清单

- [ ] **5.1 实现创建播放列表流程**
  ```objc
  // Controller: 处理用户点击
  - (void)createPlaylist:(id)sender {
      UIAlertController* alert = [UIAlertController alertControllerWithTitle:@"新建播放列表" ...];
      
      __weak typeof(self) weakSelf = self;
      [alert addAction:[UIAlertAction actionWithTitle:@"创建" style:... handler:^(UIAlertAction * _Nonnull action) {
          NSString* name = alert.textFields.firstObject.text;
          // 调用 Model 创建
          [weakSelf.model createPlaylistWithName:name completion:^(BOOL success, NSString* playlistId) {
              dispatch_async(dispatch_get_main_queue(), ^{
                  // 更新 View
                  [weakSelf.mainView.collectionView reloadData];
                  // 可以滚动到新创建的播放列表
              }];
          }];
      }]];
      
      [self presentViewController:alert animated:YES completion:nil];
  }
  ```

- [ ] **5.2 实现删除播放列表**
  - 添加长按手势识别
  - 显示操作菜单
  - 调用 Model 删除
  - 刷新 View

- [ ] **5.3 实现点击跳转详细页面**
  ```objc
  - (void)collectionView:(UICollectionView*)collectionView didSelectItemAtIndexPath:(NSIndexPath*)indexPath {
      // 从 Model 获取数据
      XC_YYAlbumData* playlist = self.model.filteredPlaylists[indexPath.row];
      
      // Controller 创建并配置详细页面
      XCALbumDetailViewController* detailVC = [[XCALbumDetailViewController alloc] init];
      detailVC.model.mainImaUrl = playlist.coverImgUrl;
      detailVC.model.playerlistName = playlist.name;
      
      // Controller 发起网络请求（如果需要）
      [[XCNetworkManager sharedInstance] getDetailOfAlbumFromWY:detailVC.model.playerList 
                                                      ofAlbumId:playlist.albumId 
                                                 withCompletion:^(BOOL success) {
          if (success) {
              // Controller 执行页面跳转
              [self.navigationController pushViewController:detailVC animated:YES];
          }
      }];
  }
  ```

## 开发顺序建议

### 推荐实现顺序 (MVC)

| 顺序 | 模块 | 预计时间 | 依赖 | 说明 |
|------|------|----------|------|------|
| 1 | Phase 1 Model 层 | 3-4h | 无 | 先搭建数据层，不依赖 UI |
| 2 | Phase 2 View 层 | 3-4h | 无 | View 层也可以独立开发 |
| 3 | Phase 3 Controller 层 | 2-3h | Phase 1, 2 | 整合 Model 和 View |
| 4 | Phase 4 搜索筛选 | 2-3h | Phase 1, 3 | 完善 Model 和 Controller |
| 5 | Phase 5 数据交互 | 3-4h | Phase 1-4 | 完整功能实现 |
| 6 | Phase 6 测试优化 | 2-3h | Phase 1-5 | 收尾工作 |

**总计预计时间：15-21 小时**

### MVC 开发要点

1. **先开发 Model 层**：Model 层不依赖其他层，可以独立开发和测试
2. **并行开发 View 层**：View 层也可以使用假数据独立开发
3. **Controller 层整合**：Controller 负责将 Model 和 View 连接起来
4. **避免跨层调用**：View 不直接调用 Model，Model 不直接更新 View

## 关键代码片段

### Model 层数据变更通知

```objc
// XCPersonalModel.m
static NSString* const kPlaylistDataChangedNotification = @"PlaylistDataChangedNotification";

- (void)notifyDataChanged {
    [[NSNotificationCenter defaultCenter] postNotificationName:kPlaylistDataChangedNotification 
                                                        object:self];
}

// Controller 订阅通知
- (void)viewDidLoad {
    [[NSNotificationCenter defaultCenter] addObserver:self 
                                             selector:@selector(handleDataChanged:) 
                                                 name:kPlaylistDataChangedNotification 
                                               object:nil];
}

- (void)handleDataChanged:(NSNotification*)notification {
    [self.mainView.collectionView reloadData];
}
```

```objc
// XCPersonalViewController.m

            // 5. 执行页面跳转

        }
    }];
}
```

## 风险与应对

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| MVC 分层不清晰 | 中 | 高 | 严格遵循文档中的职责划分，Code Review 时重点检查 |
| Controller 臃肿 | 中 | 中 | 将业务逻辑下沉到 Model，View 事件通过代理传递 |
| 详细页面复用不兼容 | 中 | 高 | 提前测试 XCALbumDetailViewController 的接口 |
| 数据存储性能问题 | 低 | 中 | 使用 NSUserDefaults 存储简单数据，复杂数据用 WCDB |
