# 编译问题修复指南

> 如果代码无法编译，请按以下步骤修复

---

## 问题 1: Header 文件找不到

### 错误信息
```
'XCPersonalViewController.h' file not found
'XCPersonalModel.h' file not found
```

### 解决方案

#### 方法 1: 添加 Header Search Paths

1. 在 Xcode 中选中项目 (Spotify - clone)
2. 选择 Targets -> Build Settings
3. 搜索 "Header Search Paths"
4. 添加以下路径：
```
$(SRCROOT)/Spotify - clone/8. 个人播放列表界面/Controller
$(SRCROOT)/Spotify - clone/8. 个人播放列表界面/Model
$(SRCROOT)/Spotify - clone/8. 个人播放列表界面/View
$(SRCROOT)/Spotify - clone/8. 个人播放列表界面/View/cells
$(SRCROOT)/Spotify - clone/8. 个人播放列表界面/View/views
$(SRCROOT)/Spotify - clone/数据结构
$(SRCROOT)/Spotify - clone/详细页面
```

5. 确保设置为 `recursive` 或 `non-recursive` 都可以

#### 方法 2: 使用 Bridging Header（如果方法1无效）

1. 打开 `Spotify - clone-Bridging-Header.h`
2. 添加以下内容：
```objc
// 个人播放列表界面
#import "XCPersonalViewController.h"
#import "XCPersonalModel.h"
#import "XCLocalPlaylistInfo.h"
#import "XCPersonalView.h"
#import "XCPersonalLoginProtocol.h"
#import "XCPersonalGridCell.h"
#import "XCPersonalListCell.h"
```

## 问题 2: 文件未添加到 Compile Sources

### 错误信息
```
Undefined symbols for architecture x86_64:
  "_OBJC_CLASS_$_XCPersonalViewController", referenced from:
```

### 解决方案

1. 在 Xcode 中选中项目
2. 选择 Targets -> Build Phases
3. 展开 "Compile Sources"
4. 检查是否包含以下文件：
   - XCPersonalViewController.m
   - XCPersonalModel.m
   - XCLocalPlaylistInfo.m
   - XCPersonalView.m
   - XCPersonalLoginProtocol.m
   - XCPersonalGridCell.m
   - XCPersonalListCell.m
   - XCPersonalEmptyView.m
   - XCPersonalLoginView.m
   - XCCreatePlaylistView.m
   - XCPlaylistSortMenu.m

5. 如果缺失，点击 "+" 添加

## 问题 3: 清理和重建

### 操作步骤

```bash
# 1. 在 Xcode 中执行
Cmd + Shift + K    # 清理 Build 文件夹
Cmd + Shift + Option + K   # 深度清理
Cmd + B            # 编译
Cmd + R            # 运行
```

或者手动删除 Derived Data：
```bash
rm -rf ~/Library/Developer/Xcode/DerivedData
```
