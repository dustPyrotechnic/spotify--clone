# 搜索页面三状态设计方案

> 文档创建日期：2026-02-21  
> 目标：实现搜索框聚焦前/聚焦后/搜索后的三状态切换界面

---

## 一、需求概述

### 1.1 当前状态
搜索页面目前只有一个测试按钮，需要重构为完整的三状态搜索界面。

### 1.2 目标状态
实现三种不同的界面状态，根据用户交互自动切换：

```
状态流转图:

┌──────────────┐      点击搜索框      ┌──────────────┐
│   默认状态    │ ───────────────────▶ │   预测状态    │
│  (Browse页)  │                      │ (Suggestions) │
└──────────────┘                      └──────────────┘
       ▲                                       │
       │                                       │ 输入文字
       │                                       ▼
       │                              ┌──────────────┐
       │                              │   搜索状态    │
       └──────────────────────────────│  (Results)   │
           点击取消/清空               └──────────────┘
```

### 3.3 状态切换逻辑

```objc
// XCSearchViewController 核心状态切换方法
- (void)transitionToState:(XCSearchPageState)state {
    _currentState = state;
    
    // 隐藏所有状态视图
    self.mainView.browseView.hidden = YES;
    self.mainView.suggestionsView.hidden = YES;
    self.mainView.resultsView.hidden = YES;
    
    // 显示对应状态视图
    switch (state) {
        case XCSearchPageStateBrowse:
            self.mainView.browseView.hidden = NO;
            [self loadHotSearchData];
            [self loadSearchHistory];
            break;
            
        case XCSearchPageStateSuggestions:
            self.mainView.suggestionsView.hidden = NO;
            break;
            
        case XCSearchPageStateResults:
            self.mainView.resultsView.hidden = NO;
            [self.mainView.resultsTableView reloadData];
            break;
    }
}
```

## 五、交互流程设计

### 5.1 关键交互处理

```objc
#pragma mark - UISearchBarDelegate

// 搜索框即将聚焦 - 切换到预测状态
- (BOOL)searchBarShouldBeginEditing:(UISearchBar *)searchBar {
    if (self.currentState == XCSearchPageStateBrowse) {
        [self transitionToState:XCSearchPageStateSuggestions];
    }
    return YES;
}

// 搜索框文字变化 - 实时获取建议
- (void)updateSearchResultsForSearchController:(UISearchController *)searchController {
    NSString *searchText = searchController.searchBar.text;
    
    // 防抖处理
    [self.searchDebounceTimer invalidate];
    self.searchDebounceTimer = [NSTimer scheduledTimerWithTimeInterval:0.3
                                                                target:self
                                                              selector:@selector(fetchSuggestions:)
                                                              userInfo:@{@"text": searchText}
                                                               repeats:NO];
}

// 点击搜索按钮 - 切换到结果状态
- (void)searchBarSearchButtonClicked:(UISearchBar *)searchBar {
    NSString *keyword = searchBar.text;
    
    // 保存搜索历史
    [[XCSearchHistoryManager sharedInstance] addSearchKeyword:keyword];
    
    // 切换到结果状态
    [self transitionToState:XCSearchPageStateResults];
    
    // 执行搜索
    [self.model searchWithKeywords:keyword];
}

// 点击取消按钮 - 返回浏览状态
- (void)searchBarCancelButtonClicked:(UISearchBar *)searchBar {
    [self transitionToState:XCSearchPageStateBrowse];
}
```
