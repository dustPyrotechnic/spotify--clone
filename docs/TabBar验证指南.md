## 2. 验证功能清单

### 基础显示 ✅

| 检查项 | 预期结果 | 操作 |
|--------|----------|------|
| 默认播放列表 | 显示"喜爱的歌曲" | 首次进入自动创建 |
| 网格视图 | 2列网格布局 | 默认显示模式 |
| 封面图 | 显示音乐图标占位 | 网格/列表都有 |
| 播放列表名称 | 显示在封面下方/右侧 | - |
| 歌曲数量 | 显示"0首" | 新创建的播放列表 |

### 导航栏功能 ✅

| 按钮 | 功能 | 操作 |
|------|------|------|
| **+** (创建) | 弹出创建播放列表弹窗 | 点击后输入名称创建 |
| **筛选** | 显示排序菜单 | 5种排序方式 |
| **切换视图** | 网格/列表切换 | 点击切换图标变化 |
| **搜索栏** | 实时搜索过滤 | 输入文字过滤列表 |

### 操作验证步骤

#### 1. 创建播放列表
```
1. 点击导航栏 "+" 按钮
2. 在弹窗中输入 "我的新歌单"
3. 点击 "创建"
4. 验证：新播放列表出现在列表顶部
```

#### 2. 切换视图模式
```
1. 点击导航栏 "切换视图" 按钮（网格/列表图标）
2. 验证：布局从网格变为列表（或反之）
3. 再次点击切换回来
```

#### 3. 排序功能
```
1. 点击导航栏 "筛选" 按钮
2. 选择 "名称 A-Z"
3. 验证：播放列表按名称排序
```

#### 4. 搜索过滤
```
1. 点击搜索栏
2. 输入 "喜爱"
3. 验证：只显示匹配的播放列表
4. 清除搜索，显示全部
```

#### 5. 长按菜单
```
1. 长按任意播放列表（非"喜爱的歌曲"）
2. 验证：弹出操作菜单（编辑/删除）
3. 点击"编辑名称"修改名称
4. 或点击"删除"删除播放列表
```

#### 6. 点击进入详情
```
1. 点击任意播放列表
2. 验证：跳转到详细页面
3. 显示播放列表封面和歌曲列表
```

## 3. DEBUG 测试功能

### 开启测试按钮

在 DEBUG 模式下，导航栏右侧会显示"测试"按钮。

### 测试菜单功能

| 选项 | 功能 |
|------|------|
| 添加5条测试数据 | 快速生成5个测试播放列表 |
| 添加20条测试数据 | 生成20个测试数据，用于测试滚动 |
| 清除所有数据 | 清空所有播放列表（保留"喜爱的歌曲"） |
| 切换视图模式 | 快速切换网格/列表 |
| 测试登录视图 | 显示登录提示界面（预留） |

### 使用测试数据验证

```
1. 点击"测试"按钮
2. 选择"添加20条测试数据"
3. 验证：列表出现20个新播放列表
4. 测试搜索：输入"测试播放列表 1"
5. 验证：显示匹配的结果
6. 测试排序：选择"最多歌曲"
7. 验证：按歌曲数量排序
8. 滚动列表，测试流畅度
9. 测试完成后，点击"清除所有数据"
```

## 4. 视图模式对比

### 网格视图 (Grid)
```
┌─────────┐  ┌─────────┐
│  封面   │  │  封面   │
│  图片   │  │  图片   │
├─────────┤  ├─────────┤
│ 名称    │  │ 名称    │
│ 50首    │  │ 20首    │
└─────────┘  └─────────┘
```

**特点：**
- 2列布局
- 正方形封面
- 封面下方显示名称和数量
- 适合浏览封面

### 列表视图 (List)
```
┌────┬─────────────────┬──┐
│    │ 播放列表名称     │ >│
│ 封面│ 50首 · 红尘一笑 │  │
│    │                 │  │
└────┴─────────────────┴──┘
```

**特点：**
- 单行布局
- 左侧小封面
- 右侧显示详情和箭头
- 适合快速查找

## 6. 常见问题排查

### 问题 1: Tab 切换后空白

**原因：** 数据未加载完成

**解决：** 等待几秒，或下拉刷新（如已实现）

### 问题 2: 创建播放列表失败

**原因：** 名称重复或为空

**解决：** 确保输入有效名称

### 问题 3: 图片加载慢

**原因：** 网络问题或占位图

**解决：** 正常现象，真实封面需要网络加载

### 问题 4: 编译错误

**错误：** 找不到头文件

**解决：** 检查文件路径是否正确，清理 Build 文件夹后重新编译

```
Cmd+Shift+K  // 清理
Cmd+B        // 编译
Cmd+R        // 运行
```
