# 歌曲评论功能设计方案

> 文档版本: 1.0  
> 创建日期: 2026-03-03  
> 适用范围: iOS Spotify Clone 播放详情页评论模块

---

## 1. 概述

### 1.1 背景
在播放详情页（XCMusicPlayerViewController）中集成歌曲评论展示功能，用户可通过底部评论入口按钮唤起评论面板，采用向上滑动动画同时移动播放控制区域，露出评论区。

### 1.2 设计目标
- 评论展示与播放控制区域协同动画，流畅自然
- 长评论支持折叠/展开，优化阅读体验
- 延迟预加载策略，点击评论按钮时零延迟展示
- 不缓存评论数据，仅保留当前歌曲评论，切歌即释放内存
- 遵循现有 MVC 架构

## 4. 长评论适配设计

### 4.1 长评论判定

```objc
#define kXCCommentLongThreshold 120  // 字符数阈值
#define kXCCommentMaxLinesCollapsed 3 // 折叠状态显示行数
```

### 4.2 高度计算策略

**预计算时机**：数据加载完成后立即计算，缓存到 `XCSongCommentList`

```
短评论：
  height = 头像区(50) + 昵称(20) + 内容高度(实际) + 底部栏(30) + 间距(20)

长评论（折叠）：
  height = 头像区(50) + 昵称(20) + 内容高度(3行) + 展开按钮(24) + 底部栏(30) + 间距(20)

长评论（展开）：
  height = 头像区(50) + 昵称(20) + 内容高度(全文) + 底部栏(30) + 间距(20)
```

### 4.3 展开/收起流程

```
用户点击「展开」
    ↓
Controller 调用 Model.commentList.updateExpandState:YES forCommentId:id
    ↓
Model 重新计算该评论的高度 → 更新高度缓存
    ↓
Controller 执行 tableView.beginUpdates + endUpdates
    ↓
View 动画刷新高度，按钮文字变为「收起」
```

## 5. 网络请求层设计

### 5.1 架构层次

```
XCMusicPlayerViewController
    ↓ 调用
XCSongCommentService (网络层单例)
    ↓ 发起请求
NSURLSession
    ↓ 返回数据
XCSongCommentList (解析+缓存)
    ↓ 通知更新
XCMusicPlayerViewController 刷新 UI
```

### 5.2 XCSongCommentService 职责

- 封装网易云 API `/comment/music`
- 请求管理：支持按 `songId` 取消请求
- 错误处理：超时15s，失败重试1次
- 不做数据解析，返回原始 NSDictionary

### 5.3 预加载策略（无缓存）

**设计原则**：评论数据不做持久缓存，仅对当前歌曲做内存预加载，切换歌曲时丢弃旧数据。

**延迟预加载机制**：

```
用户切歌到 Song A
    ↓
XCMusicPlayerModel 开始播放（优先保证音频）
    ↓
延迟 2 秒（dispatch_after）
    ↓
后台线程请求 /comment/music?id=SongA&limit=20
    ↓
返回数据 → 存入 XCSongCommentList（内存中，仅当前歌曲）
    ↓
用户点击评论按钮
    ↓
检查是否已加载？
    ├─ 已加载：直接展示评论面板，零延迟
    └─ 未加载（快速点击）：显示 Loading，立即请求数据

用户快速切歌到 Song B（<2秒）
    ↓
自动取消 Song A 的请求
    ↓
丢弃 Song A 的评论数据（释放内存）
    ↓
开始 Song B 的预加载流程
```

**内存管理**：
- 只保留当前播放歌曲的评论数据
- 切歌时自动释放上一首的评论内存
- 不限制条目数，因为只有 1 条（当前歌曲）

## 8. 与现有系统集成

### 8.1 与 XCMusicPlayerModel 集成

在切歌逻辑中注入预加载（无缓存，仅当前歌曲）：

```objc
// XCMusicPlayerModel.m

@interface XCMusicPlayerModel ()
@property (nonatomic, strong) XCSongCommentList *preloadedCommentList;  // 仅当前歌曲
@property (nonatomic, strong) NSURLSessionDataTask *commentPreloadTask;
@end

- (void)playSong:(XC_YYSongData *)song {
    // ... 原有播放逻辑 ...
    
    // 取消上一首的预加载请求
    [self.commentPreloadTask cancel];
    
    // 丢弃上一首的评论数据（释放内存）
    self.preloadedCommentList = nil;
    
    // 延迟预加载当前歌曲评论
    __weak typeof(self) weakSelf = self;
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(2.0 * NSEC_PER_SEC)), 
                   dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_LOW, 0), ^{
        __strong typeof(weakSelf) strongSelf = weakSelf;
        if (!strongSelf) return;
        
        // 只预加载当前播放的歌曲
        if (![strongSelf.nowPlayingSong.songId isEqualToString:song.songId]) return;
        
        strongSelf.commentPreloadTask = [[XCSongCommentService sharedInstance] 
            fetchCommentsForSongId:song.songId 
                             limit:20 
                            before:nil 
                        completion:^(NSDictionary *response, NSError *error) {
            if (!error && response) {
                strongSelf.preloadedCommentList = [[XCSongCommentList alloc] initWithDictionary:response];
            }
        }];
    });
}

// 提供给 Controller 获取预加载数据
- (XCSongCommentList *)getPreloadedCommentList {
    return self.preloadedCommentList;
}
```

## 9. 性能考虑

| 优化点 | 方案 |
|--------|------|
| 列表滑动 | 预计算高度，不使用 UITableViewAutomaticDimension |
| 长评论渲染 | YYLabel 异步渲染富文本 |
| 图片加载 | SDWebImage 复用现有方案 |
| 内存管理 | 只保留当前歌曲评论，切歌立即释放，无累积 |
| 网络优化 | 延迟预加载，快速切歌时取消请求 |
| 动画性能 | 使用 transform 位移，不触发 layout |

### 10.6 楼层评论 Cell 设计

**XCSongCommentFloorCell**

与普通评论 Cell 的区别：
- **缩进层级**：根据回复层级显示不同左边距（每层缩进 16pt）
- **回复线**：左侧显示灰色竖线连接回复关系
- **折叠策略**：超过 3 层的回复默认折叠，显示「展开更多回复」

```objc
@interface XCSongCommentFloorCell : UITableViewCell

```

**视觉表现**：
```
层级 0（楼主）: 无缩进
层级 1: 左边距 16pt
层级 2: 左边距 32pt  + 左侧灰色竖线
层级 3: 左边距 48pt  + 左侧灰色竖线
```

```
    ↓
Controller 创建 XCSongCommentFloorViewController
    ↓
传递参数：parentComment=comment, songId=songId
    ↓
楼层页调用 Service fetchFloorComments
    ↓

    ↓

    ↓
```
